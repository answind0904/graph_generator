# Graph Generator

브라우저에서 그래프를 만들고 이미지로 저장할 수 있는 정적 웹 애플리케이션입니다.

## 라인 그래프 PSD 편집

라인 그래프의 **PSD 저장**은 데이터셋별 선, 마커, 하단 채우기를 Photoshop 쉐이프 레이어로 내보냅니다. 레이어 이름에는 입력한 데이터셋 이름이 붙습니다(예: `선_매출`, `마커_매출`).

Photoshop의 직접 선택 도구로 앵커 포인트를 수정하거나, 쉐이프의 스트로크 색상·두께·점선을 변경할 수 있습니다. 마커와 하단 채우기는 각각 독립된 쉐이프이므로 선의 점을 이동해도 자동으로 따라 움직이지 않습니다. 수치·제목·축은 기존 픽셀 레이어로 저장됩니다.
