# Graph Generator

브라우저에서 그래프를 만들고 이미지로 저장할 수 있는 정적 웹 애플리케이션입니다.

## 라인 그래프 PSD 편집

라인 그래프의 **PSD 저장**은 데이터셋별 선, 마커, 하단 채우기를 Photoshop 쉐이프 레이어로 내보냅니다. 레이어 이름에는 입력한 데이터셋 이름이 붙습니다(예: `선_매출`, `마커_매출`).

Photoshop의 직접 선택 도구로 앵커 포인트를 수정하거나, 쉐이프의 스트로크 색상·두께·점선을 변경할 수 있습니다. 마커와 하단 채우기는 각각 독립된 쉐이프이므로 선의 점을 이동해도 자동으로 따라 움직이지 않습니다. 수치·제목·축은 기존 픽셀 레이어로 저장됩니다.

## 막대그래프 수치 텍스트 (테스트)

일반 막대그래프의 PSD 저장은 PC에 MBC 새로움 Medium이 설치되어 있으면 수치를 편집 가능한 텍스트로 저장합니다. `수치_데이터셋이름` 그룹 안에 각 숫자가 독립된 텍스트 레이어로 들어갑니다. MBC 새로움이 없거나 브라우저가 로컬 폰트 사용을 허용하지 않으면 기존 픽셀 수치로 저장합니다.

폰트는 `local()`로만 사용하고, PSD에는 폰트 이름과 텍스트 설정만 기록합니다. MBC 폰트 파일을 다운로드·복사·업로드·임베딩하지 않습니다. 편집할 PC에도 같은 폰트가 설치되어 있어야 합니다. 화면 UI·미리보기와 제목·축·범례의 폰트 설정은 변경하지 않습니다.
